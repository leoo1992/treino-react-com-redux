# Treino React com Redux

Projeto de estudo para praticar a integração do Redux com componentes React, organizando o estado da interface em uma store central.

## Stack
- React 18
- Redux
- JavaScript
- Create React App

## Como executar

```bash
npm install
npm start
```

Acesse http://localhost:3000. Testes: `npm test`; build: `npm run build`.
